# 🏡 Unser Zuhause – Weihnachtsabenteuer 🎄

Ein kleines, liebevoll gestaltetes 2D-Weihnachtsspiel für meine Familie. ❤️

In diesem Spiel kannst du unser Zuhause erkunden, Familienmitglieder treffen und mit unseren Haustieren interagieren.

##  Spielbeschreibung

Willkommen zu Hause!

Schlüpfe in die Rolle von **Marei** und erkunde eine selbst gestaltete Pixelwelt voller vertrauter Gesichter.

Entdecke die verschiedenen Räume, sprich mit deiner Familie und besuche unsere tierischen Mitbewohner.

Das Spiel ist ein persönliches Weihnachtsgeschenk. 

##  Features

-  Eine selbst gestaltete Hauskarte
-  Marei als steuerbare Spielfigur mit Laufanimationen
-  Familienmitglieder mit eigenen Dialogen
-  Katzen und Hund als kleine Spielcharaktere
-  Animierte Tiere und bewegliche Figuren
-  Dialogsystem zum Ansprechen der Charaktere
-  Kollisionen mit Wänden und Hindernissen
-  Kamerazoom mit dem Mausrad

##  Steuerung

| Taste | Aktion |
|---|---|
| W / A / S / D | Bewegen |
| Pfeiltasten | Bewegen |
| E | Mit Charakteren sprechen |
| Mausrad | Rein- und rauszoomen |
| K | Kollisionsfelder anzeigen |

Du kannst Charaktere auch mit der Maus anklicken, um mit ihnen zu sprechen.

##  Charaktere

Im Spiel begegnest du unter anderem:

**Familie:** Mama, Papa, Joris, Bjarne, Swantje, Kai, Steffi, Jari und Lia.

**Haustiere:** Emil 🐶, Fiete 🐱, Henri 🐈‍⬛ und Alfie 🐱.

Jeder hat seinen eigenen kleinen Platz in unserem Zuhause.

##  Technik

Das Spiel wurde mit folgenden Technologien erstellt:

- HTML
- JavaScript
- Phaser 3
- Tiled-/SpriteFusion-Tilemap
- Pixel-Art-Sprites

##  Lokal starten

1. Repository herunterladen.
2. Die Dateien in einem lokalen Webserver bereitstellen, beispielsweise mit WampServer.
3. `index.html` über `localhost` im Browser öffnen.

Alternativ kann das Spiel über GitHub Pages veröffentlicht und direkt im Browser gespielt werden.
